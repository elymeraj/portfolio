Personal portfolio presenting my professional experience, selected projects, and technical skills across machine learning, computer vision, natural language processing, trustworthy AI, and data engineering.

The website is available in English and French and includes dedicated links to both versions of my resume.

[elymeraj.github.io/portfolio](https://elymeraj.github.io/portfolio/)

- Light and dark themes
- Responsive layout for desktop and mobile

## Run locally

### Requirements

- Node.js 16 or later
- npm

### Installation

```bash
git clone https://github.com/elymeraj/portfolio.git
cd portfolio
npm install
npm start
```

The development server is available at [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

The generated `build/` directory is intentionally excluded from the main branch.

## Deployment

```bash
npm run deploy
```

The deployment script publishes the production build to the `gh-pages` branch.

## Project structure

```text
public/                 Static files and localized resumes
src/components/        Reusable interface components
src/contexts/          Language and theme state
src/portfolio.js       English and French portfolio content
```
